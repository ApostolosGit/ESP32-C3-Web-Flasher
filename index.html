ESP32-C3 SuperMini • OLED 1.3" SH1106

Web Flasher & OTA

USB firmware installation

Σύνδεσε την πλακέτα με καλώδιο USB δεδομένων και άνοιξε τη σελίδα από Chrome ή Edge σε desktop. Το USB flash μπορεί να διαγράψει προηγούμενα δεδομένα.

Έλεγχος αν έχει δημοσιευτεί εγκεκριμένο firmware…
Χρειάζεται Chrome/Edge με Web Serial.

OTA via local Wi-Fi

Το OTA πραγματοποιείται από τη συσκευή, όχι απευθείας από το GitHub Pages. Συνδέσου στο Wi-Fi της συσκευής C3-OLED-Setup και άνοιξε http://192.168.4.1/, ή χρησιμοποίησε την IP που εμφανίζει η OLED. Επίλεξε το νέο firmware.bin από τα ιδιωτικά build artifacts.

Συνδέσεις OLED

GND → GND · VCC → 3V3 · SCL → GPIO4 · SDA → GPIO3

Πριν από την κόλληση, έλεγξε τη σειρά pin και τη μηχανική ευθυγράμμιση.

Τα δοκιμαστικά binaries δεν δημοσιεύονται αυτόματα. Η δημόσια σελίδα δεν περιέχει πηγαίο κώδικα firmware ή κωδικούς Wi-Fi.
