# ESP32-C3 OLED Web Flasher (PUBLIC)

Public web interface for the ESP32-C3 SuperMini OLED firmware.

**Private firmware source/builds:** https://github.com/ApostolosGit/ESP32-C3-OLED-OTA (authorized account required).

This repository contains the UI only. It intentionally does not contain firmware binaries or real device credentials.

Enable **Settings → Pages → Build and deployment → GitHub Actions**. Visit https://apostolosgit.github.io/ESP32-C3-Web-Flasher/ after the Pages workflow finishes.

To allow USB flashing later, manually upload a **reviewed, credential-free** `firmware/factory.bin` and `manifest.json` to this public repository. Manifest example:

```json
{"name":"ESP32-C3 OLED","version":"1.0.0","builds":[{"chipFamily":"ESP32-C3","parts":[{"path":"./firmware/factory.bin","offset":0}]}]}
```

The site checks that both files exist. **Do not upload private firmware binaries containing passwords, API keys or personal Wi-Fi configuration.** An OTA `firmware.bin` is separate from the merged USB `factory.bin`. OTA happens via the board's local web interface, using the firmware generated by the private build.
